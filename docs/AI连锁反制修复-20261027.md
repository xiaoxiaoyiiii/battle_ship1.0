# AI连锁反制修复与验收

修复了“AI发动轰炸、玩家用失灵响应，大师却在结算后才单独发动加百列之光”的问题。现在困难与大师会在当前响应窗口中选择合法反制，原场景形成轰炸、失灵、加百列三项同链，随后按加百列、失灵、轰炸倒序结算。

## 实现

- 开窗资格和真实响应共用同一个反制选择入口，避免允许响应却选不到牌。困难、大师和按座位覆盖的难度都使用该入口；简单、普通保留原有分工。
- 能用失灵时优先保留加百列，其次检查平等条约，最后选择加百列。遵守真实免疫、出牌限制及平等条约的船数变化判据，不反制自己的栈顶，不把其他速阶三卡自动当作反制牌。
- 响应任务醒来时重新检查当前手牌；卡牌已经离手则让过并正常结算，不留下空窗口。
- 大师不再仅根据已结算的魔法历史主动使用加百列；有效连锁反制和拆除当前场地的用途保留。
- 未改动牌效、协议、数据库结构或前端。0.8秒接链演出及之后完整10秒响应窗口保持原有时序。
