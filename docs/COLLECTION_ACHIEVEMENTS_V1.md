# 航海图鉴、成就与熟练光效 v1

图鉴为 `/collection` 独立页面。旧顶栏、头像菜单、首页和设置中的入口沿用原来的打开动作，由壳层统一导航到新页。

## 计数与奖励

所有计数从本版本上线后的有效对局开始，不回溯旧 `user_card_usage`、总胜场或旧徽章。后端卡表按卡名归并为48种，速阶变体共享该卡的点亮与熟练记录。

| 范围 | 图鉴点亮 | 熟练次数与每卡胜场 | 新成就 |
| --- | --- | --- | --- |
| 休闲匹配、排位 | 是 | 是 | 是 |
| 人机 | 是 | 否 | 否 |
| 每日挑战（完成或失败） | 是 | 否 | 否 |
| 自定义、取消局、管理员测试 | 否 | 否 | 否 |

本人需为注册账号。真人匹配中的游客对手不改变模式口径，但游客自己不获得持久进度。出牌只在合法支付、入链后采集；不接受客户端上报次数。被无效的牌仍属于已经打出的牌。同卡在一场胜利中无论打出几次，卡牌胜场只加1。普通局在有效结算事务落库，每日挑战在其独立结束事务落库。

- 每张点亮卡10徽记，12/24/36/48种分别再发50/100/150/300，合计1080；48种另发「全图鉴」。
- 熟练阈值10/50/100/500，500另发该卡宗师称号；初始所选档位为关闭，不自动替用户开启。
- 12项成就逐项奖励共1540，达标即自动到账。徽记来源为 `collection_card`、`collection_milestone`、`collection_achievement`，不进入 `match_tide` 的60日帽。
- 重复结算以 `(user_id, source_id)` 去重；奖励再由既有钱包来源唯一键去重。任何后续结算钩子失败，计数、徽记、称号与幂等记录一并回滚。

新成就的名称、阈值和奖励唯一真源为 `domain/collection.py` 的 `ACHIEVEMENTS`，不改动旧个人资料徽章系统。连胜只由有效真人匹配/排位推进或打断。闪电战含第5回合；断链者须成功用失灵打断两条不同连锁；深潜连锁须本人参加至少4层链且获胜。孤舰翻盘要求己方1艘、对方多于1艘时曾处劣势；整场战损事实不被复活清除，主动牺牲亦计战损。

## 外观与隐私

已选档位冻结在本次公开出牌的 `ChainItem.mastery_tier`。公开连锁和结算附带0至4档，关闭或旧载荷缺省为0。实战手牌仅本人从自己的图鉴读取光效；对方手牌背面不附带任何卡名、熟练或档位信息。观战与回放仅透传已经公开的连锁光效，不改录像规则或重新计算战斗。

四档使用青蓝、紫曜、熔金、虹潮外观；第四档循环外观尊重系统与应用的减少动态设置。图鉴可自选所有已解锁档位或关闭；切档不扣徽记、不改变次数、解锁或称号。

称号复用 `user_cosmetic_rewards` 和现有资料装备系统。通用称号为 `collection_complete`、`collection_commander`、`collection_last_ship`、`collection_untouched`、`collection_all_cards`；单卡称号ID为 `card_mastery_` 加卡名SHA256的前12位，展示名称为“卡名＋宗师”。

## 接口与迁移

- `GET /api/collection`：只返回当前会话本人48卡、里程碑、12成就和余额，未登录401，响应不缓存。
- `POST /api/collection/mastery`：`{card_name, tier}`，身份只取会话；非法名称、布尔/非整数/未解锁档位400。响应 `{ok, selected_tier}` 或 `{ok:false,error}`。不提供替别人修改的参数。
- `0014_collection` 接 `0013_daily_checkin`，新增 `collection_cards`、`collection_progress`、`collection_settlements`，不修改旧表。降级仅删除新增三表，因此会清除本功能的新计数；既有账号、钱包、奖励账本和称号表保留。
