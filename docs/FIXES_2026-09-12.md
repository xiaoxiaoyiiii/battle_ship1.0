## 二、P1（功能错误 / 可利用）— 已修复

- **增援/复活退还已用攻击次数**（`c1257e0` 引入的回归）：改为按**增量**同步，保留已消耗次数；伊甸园（次数=6-船数）按 -1/艘、教皇旨意不计。
- **`chain_response` 绕过封锁 + 伪造卡牌类型**：补 `can_play_magic_card` 校验（禁忌果实/绝处逢生），并改用服务端手牌里的真实卡牌实例（忽略客户端伪造的 speed/type/description）。
- **`papal_attack` 可在对手回合攻击 / 越界索引零代价攻击**：补回合与阶段校验、弃卡索引越界直接拒绝。
- **`chat_message` 任意房间发言**：要求发送者确实坐在该房间。
- **`ships_updated` 视角错位**（被轰炸方双方船数互换）：新增 `_emit_ships_updated`，按每个收件人自己的视角单独下发（12 处 emit 统一替换）。
- **前端 `init()` 双调用** → `bindEventListeners` 跑两遍、按钮双绑（日志折叠失效）：`init()` 加幂等守卫。
- **`#profile-save-msg` 元素缺失且无守卫** → 个人信息/签名/头像 3 处 TypeError：在 `templates/index.html` 补元素。
- **`#show-opponent-stats` 按钮缺失** → 「查看对手战绩」无入口：补按钮（JS 原本就会显示/绑定它）。
- **`#ships-placed.textContent=0` 摧毁内部 `<span id="placed-count">`** → 灵气复苏/败者食尘重摆船后计数永久显示 0：改为只更新内层 span，并补 `#total-ships`。
- **连锁面板施法者恒显示「对手」**：前端兼容 `player_id`/`caster` 字段。
- **`damage_dealt_this_turn` 永不重置**（唯一重置点在零调用死函数内）→ 五险一金/Freezing! 失效：在大回合开始与换人时归零。
- **`end_turn` 换人时攻击次数未走统一算法** → 伊甸园/教皇旨意下准备阶段数值错误：改走 `_recalc_attacker_attacks`。
- **「明智埋葬」「仁王之盾」真实链路完全无效**（实现写在无人调用的 `select_magic_target` 里）：在 `confirm_magic_target` 补 `bury_choice`/`shield_choice` 分支（带参数校验）。
- **`draw_card` 抽到重名牌必抛 `ValueError`**（`discard_card` 对不在手牌的卡调 `.index()`）：`discard_card` 改为按对象身份匹配、找不到只进弃牌堆，不再抛异常。
- **猜拳平局 `IndexError`**（约 1/3 概率打断 `rps_choice`）→ 平局直接返回并等待重新出拳。
- **「加百列之光」拆自己场地 + 场地效果残留 / `remove_field_magic` 无归属**：新增 `field_magic_owner`；拆场地/顶替时清理 `demon_contract`/`papal_edict`；只能拆自己的场地。
- **被无效化的场地卡会把场上已有场地连带扫进弃牌堆**：被 negate 的场地卡只进弃牌堆，不再「贴了再拆」。
- **「回光返照」永久有效**：效果绑定发动回合，过期即失效并在大回合结束时清理。
- **「溅射」命中回光返照使用者时返回 dict** → `resolve_chain` 抛 `AttributeError`、连锁不结算：统一改走 `_check_last_chance` 并返回 `ChainResult`。
- **「桃园结义」绕过「无中生有」的 no_draw 封锁**：封锁期间直接拒绝。
- **终局路径不写战绩**（极限增援 / 无暇圣心）：统一走 `_finish_game_win`。
- **AI 回合可能卡死**（候选格打空 / 阶段未切换 / 次数异常）：回合结束前兜底强制进入结束阶段并清零剩余次数。
- **百亿补贴 +3 加给对手**（卡面是「自己的船被击败 → 自己的攻击次数 +3」）：改为累计在持卡者 `effect_flags.subsidy_bonus`，在其回合计入攻击次数。
- **「平等条约」快照永不过期 + 只回滚船数**：快照打回合戳（只允许无效化本大回合的船数改变），并连带撤销该次击沉发放的补贴。
- **「极限增援」提前一个大回合结算**：按卡面「不算生效的这个大回合」，计数从下一个大回合才开始递减。
- **「饮血」缺少「击中后」前置校验**：无自己命中记录时不可使用。
- **db 共享游标并发风险**：`get_chat_messages`/`get_token_by_password` 改用独立游标并纳入锁。

## 三、刻意改变的对局语义（请确认是否符合预期）

1. **百亿补贴**：奖励归**持卡者**，跨回合累计（不再是给当前攻击者 +3）。
2. **饮血**：必须有自己上一次命中记录才能打出。
3. **平等条约**：只能无效化**本大回合内**的船数改变。
4. **极限增援**：结算推迟一个大回合（与卡面一致）。
5. **加百列之光 / remove_field_magic**：只能动**对方 / 自己**的场地。
6. **明智埋葬 / 仁王之盾**：从「完全无效」变为正常生效（这是本次修复最大的功能变化）。
