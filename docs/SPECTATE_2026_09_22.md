# 实时观战 —— 地基与安全（第 1 批，2026-09-22）

> 本批**只做地基 + 安全**：观众暂时还进不来（没有入口、没有加入事件、没有前端）。
> 目的是把"漏一个事件 = 透视漏洞"从**人肉约定**变成**机器穷举**，
> 后面几批再往上接大厅入口、快照、观战席、观战席聊天。

---

## 1. 产品决定（作者已定，不要改）

* **入口**：大厅里列出"进行中的对局"，点一下就能观战；**只限登录用户**；
* **列哪些**：匹配对局（排位 + 普通）+ 自定义房对局；**不含人机房**；
* **允许被观战**：玩家的**全局设置**，只由自己的设置决定；**双方都允许**才可被看；
  **在观众进入的那一刻读一次，永不踢人**；
* **观众能看到**：全部公开信息（双方剩余船数、已轰过的格子、打出的牌、连锁、对局日志）
  + **双方手牌张数**（只看张数不看内容）+ **玩家之间的聊天**；
* **观战席**：玩家只看到**人数**（不看名单）；观众彼此看得到名字；**上限 20 人**；
* **观战席聊天**：**对局双方不可见**；
* **实时**：真·实时、无延迟；中途加入要立刻拿到当前局面的快照。

### 核心不变量（按重要性）

1. ★ **观战者永远拿不到船的位置** —— 任何发给观战通道的 payload 里**不存在**
   `ships` / `positions` / `hits`；
2. ★ **双方所有动作都看得到**（漏一个就是"看得到但不全"）；
3. ★ **实时**（中途加入拿快照，之后逐动作推）；
4. 观战席与观战聊天。

## 3. 为什么要有 `spectate.py`（而不是在 `server.py` 里判）

与 `ranks.py` / `anticheat.py` / `quick_chat.py` 同一套路：**纯函数、无 I/O、无 socket、
不 `import server`**（CLAUDE.md 教训 #19）。这样：

* 表本身可以被单测直接枚举（39 / 41 个事件逐个走一遍净化）；
* 加事件的人**必须**在表里表态，不能靠"我记得别转发"。

### `SPECTATE_EVENTS` —— 允许给观众（值 = 净化函数，`None` = 原样转发）

**默认拒绝**：不在这张表里的事件一律不发观众。

### `NOT_FOR_SPECTATORS` —— 明确不给（值 = **理由字符串**，空理由在导入期直接报错）

写不出理由 = 没想清楚，所以理由非空是**模块导入期**的硬校验（`_validate()`）。

### ★ 三处「明文整船坐标」的房间级广播（本批最要紧的发现）

这三处对**对局双方**是公开的（设计如此），但**加上观众就是透视**：

| 事件 | `server.py` | 原 payload | 净化后 |
| --- | --- | --- | --- |
| `shields_added` | `12581` | `player` + `count` + **施法者全部存活船的坐标** | `player` + `count` |
| `trap_set` | `9346` / `12552` | `player` + **设陷阱那艘船的坐标** | `player` |
| `shield_absorbed` | `4621` | `player` + **挨打那艘船的全部坐标** | `player` |
| `trap_triggered` | `4437` / `4443` | `owner` + **被击沉那艘船的坐标** + `sacrificed` | `owner` + `sacrificed` + `message` |
| `ship_sacrificed` | `10470` / `12229` | `player` + **被牺牲那艘船的坐标** + `reason` | `player` + `reason` + `sacrificed_cells`（格数） |

⚠️ `shield_absorbed` 的危害**在单格船上看起来是零**（挨打那艘船的坐标 = 已经被
`attack_result` 公开的那一格）。多格船才暴露出来：它会把**从没挨过炮的那一格**
也送出去。守卫测试专门用**两格船**钉住这一点。

⚠️ `magic_chain_updated` 广播的是 `room.chain`（`ChainItem` 列表），走的是
`emit` 的 `default=lambda o: o.__dict__` **全量序列化** —— 所以
`player_id`（**匹配房里是 socket sid**）和客户端提交的 `targets` 都在 payload 里。
净化函数把 `targets` 整个剥掉（形状不受控，可能是坐标），`player_id` 保留并加了
`seat` 别名与说明 —— 要不要换成 `p1`/`p2` 座位标签留给后续批次与作者定夺。

## 4. 通道怎么分的（`emit` 的第三条腿）

```
玩家 ──join_room(room_id)──► socket.io room = <room_id>        ← 93 处房间级广播
观众 ──（第 2 批）join_room──► socket.io room = spectate:<id>   ← 只有净化过的动作
```

* **观众绝不能进对局的 socket.io room** —— 那等于把 93 处广播（含整船坐标）原样灌给他。
  观战通道是**另一个** room 名（`spectate:` 前缀，`spectate.spectate_room_id()`）。
* 第三条腿**只对广播类**（`room=<对局房间号>`）生效：`to=<sid>` 是私人消息，不复制。
* ⚠️ **两个出口都要走**：`semit`（有请求上下文）与 `socketio.emit`（无请求上下文的后台
  任务 / 定时器）。只改一条的话，超时交回合 / 连锁超时 / 掉线判负这些广播会在观战端
  **整段消失**，观众看到的是"卡住了"。
* ⚠️ **`room=<sid>` 的门禁**（`_live_room_id`）：全文件有 5 处把 `room=player.sid` 用错
  （`572` / `1697` / `1822` / `3771` / `4072`），其中 `hand_updated` 发的是**完整手牌**。
  本批不许动那些调用点，所以门禁写在 `emit` 里 —— 房间号**必须在
  `room_manager.rooms` 里**才转发观战。顺带它也让 `room=LOBBY_ROOM`（`1184`）被正确排除。

### ⚠️ 在表里 ≠ 真的会发

有几个事件实际是 `to=<sid>` 或 `room=<sid>` 发的（`chat_message`、`opponent_disconnected`、
`opponent_reconnected`、`achievements_unlocked`、`xp_gained`、`rank_changed`），
它们**一个字节都到不了观战通道**。留在表里是**穷举分类**的要求（每一处 emit 都必须
表态），不是"观众能看到"的承诺。

## 5. 两条穷举守卫（本批的核心价值）

`tests/test_spectate_guards.py`：

### (a) 事件分类穷举

用 **AST**（不是正则）扫 `server.py` 里全部 `emit(...)` / `semit(...)` 调用点，取出事件名，
断言每个名字都落在两张表之一；并且反向断言"源码里出现的事件名 ⊆ `KNOWN_EVENTS`"，
这样**新人加事件时必须表态**。

⚠️ 扫描器取的是 emit 表达式里**所有字符串字面量**，因此
`emit('A' if cond == 'X' else 'B')` 里的 `'A'` / `'B'` / `'X'` 都会被要求交代 ——
`'X'`（不是事件名的判据值）登记在 `_NON_EVENT_STRING_LITERALS` 里并写明它是什么。
**这个设计当场就抓到了一个真漏网**：`taoyuan_choice` 只是三元表达式里的**判据值**，
按"取第一个字面量"的写法会从眼皮底下溜过去。

### (b) 无位置泄漏（**双向**）

造一个**船位已知**的房间（第 5 艘是**两格船**，只有一格挨过炮），对表里**每一个**
"给观众"的事件构造**真实形状**的 payload 走净化：

* 正向：净化结果里不含任何**未被轰过的**船坐标，也不含 `ships`/`positions`/`hits`/`sunk_positions`；
* **反向**：净化**不许把动作信息也删了** —— `attack_result` 必须仍有 `attacker`/`x`/`y`/`hit`，
  `shields_added` 必须仍有 `player`/`count`，`trap_triggered` 必须仍有 `owner`/`sacrificed`。
  防的是"为了安全把该给的也砍了"（那会让观众从"看得到动作"退化成"什么都看不到"）。

配套 `test_raw_payloads_would_have_leaked` 做**反向校准**：断言未净化的原始样例里
**确实有**没挨过炮的船位 —— 否则上面那条可能是"因为样例本来就没坐标"而假绿
（教训 #34：零报错制造假象）。
