# 战舰游戏前端 UI 美化设计（海洋军事风 · 全局改造）

日期：2026-08-27
状态：已与用户确认方向

## 目标与范围

将战舰游戏前端整体升级为「海洋军事风」视觉体系，覆盖全部界面（导航、开始界面、房间、布阵、猜拳、对局、大厅、排行榜、结算、全部弹窗）。

用户已确认的决策：

- 视觉风格：海洋军事风（深海蓝调、金属质感、氛围动效）
- 范围：全局整体改造
- 允许调整 HTML 结构与布局
- 保留深色/浅色主题切换 + 设置中的自定义主色功能
- 动效程度：适中氛围动效

实现路径：设计令牌 + 单文件整体重写 `static/style.css`（方案 A），同步清理 `templates/index.html` 内联样式。不拆分 CSS 文件、不引入 CSS 框架。

## 1. 设计令牌（CSS 变量）

`:root`（浅色/浅海主题）与 `html.theme-dark`（深色/深海主题）各定义一套完整令牌，现有令牌名全部保留（避免破坏 `rgba(var(--primary-rgb), ...)` 等既有引用），按需新增：

| 令牌 | 浅色主题 | 深色主题 | 用途 |
|------|----------|----------|------|
| --surface / --surface-strong | 天光蓝白渐变基色 | 深海蓝黑 #0a1428~#10233f | 页面背景 |
| --panel / --panel-border | rgba 白 + 毛玻璃 | rgba 深蓝 + 毛玻璃 | 面板/卡片 |
| --primary / --primary-600 | 钢蓝 #1565c0 系 | 亮海蓝 | 主操作色（可被用户自定义覆盖） |
| --primary-rgb | 与 --primary 同步 | 同步 | rgba 派生 |
| --accent | 黄铜橙 | 黄铜橙 | 点缀/强调 |
| --hit / --miss | 炮火红橙 / 水波灰蓝 | 同调提亮 | 棋盘命中/未中 |
| --danger / --success / --warning / --info | 语义色 | 语义色 | 按钮与提示 |
| --shadow-panel / --glow-primary | 柔和阴影/主色辉光 | 加深 | 层次 |

自定义主色：`game.js` 中主色选择器回调在设置 `--primary`、`--primary-600` 的基础上，同步计算并设置 `--primary-rgb`（现有实现遗漏此项，导致 `rgba(var(--primary-rgb),...)` 处不随自定义主色变化）。

## 2. 背景与氛围

- `body` 背景：垂直线性渐变（浅色：天光蓝→白；深色：深海蓝黑渐变）+ 一层微弱径向光斑。
- `#particle-canvas`（game.js `initParticles`）：粒子由「下落圆点」改为「上浮气泡」——速度取负值、带轻微左右摆动、大小与透明度分层，颜色读取当前 `--primary` 派生的半透明色。仅改该函数视觉参数，不改其余逻辑。
- `@media (prefers-reduced-motion: reduce)`：关闭全部动画与过渡。

## 3. 布局与结构重构（templates/index.html）

原则：**所有元素 id、功能 class（hit/miss/ship/hidden/active/screen 等）保持不变**，仅调整结构包裹、删除内联 `style=""`、替换为语义 class。

### 3.1 导航栏 `.nav`
- 去掉 `| ` 文本分隔，改为 flex 布局：左侧 `⚓ 战舰游戏` 徽标区，右侧菜单区（登录/注册/退出、排行榜、个人战绩、个人信息、主题切换）为胶囊链接；帮助/设置/音乐按钮收进右侧按钮组。
- 6 个模态弹窗（个人信息、设置、帮助、个人战绩、对局详情等）从 `.nav` 内部移出到 `.game-container` 直属（当前嵌套在 nav 里属于结构错误），id 不变。

### 3.2 开始界面 / 自定义房间 / 大厅 / 结算
- 开始界面：居中式英雄区，大标题带 ⚓ 元素与渐变文字，名字输入框加宽，三个入口按钮纵排（匹配游戏为主 CTA 渐变高亮，其余次级样式），在线人数改为右上角胶囊徽章。
- 自定义房间、大厅、游戏结束界面：统一套用 `.panel` 卡片容器与按钮体系。

### 3.3 游戏主界面
- 移除 `.game-main-container { margin-left: 280px }` 与 `.game-content { margin-right: 330px }` 硬编码；内容区居中，最大宽度约束。
- 游戏日志（左）、魔法卡预览（右）、聊天（右下）保留现有 `position: fixed` 可拖拽浮窗行为，但外观统一为 `.floating-panel`（毛玻璃 + 标题栏 + 统一圆角阴影），与整体令牌一致。
- 双棋盘：`.board-wrapper` 升级为带标题与描边的面板卡片；≤992px 时浮窗转静态堆叠（现有断点保留）。
- 回合/阶段指示区（`#turn-indicator`）：当前行动方高亮发光。

## 4. 组件样式体系

- **按钮**：三级——`.btn`（主：主色渐变，hover 上浮+辉光）、`.btn.secondary`（描边幽灵）、`.btn.danger`（红）。统一圆角、内边距、过渡。
- **面板**：`.panel`（毛玻璃 `backdrop-filter`、令牌边框、阴影），用于屏幕区块、棋盘卡片、弹窗内容。
- **棋盘**：格子水面微渐变；`.cell.ship` 金属灰棕渐变 + inset 高光（铆钉质感）；`.cell.hit` 炮火红橙 + 💥；`.cell.miss` 灰蓝 + 白点；保留现有 `splash-effect` 涟漪。
- **魔法卡**：`.magic-card` 卡框按类型着色边框、hover 上浮 + 主色辉光；`.magic-card.selected` 金色描边（保留）。
- **模态弹窗**：统一现有 `.modal-overlay`（深色模糊遮罩 + slideUp 入场），标题加分隔线与 ⚓ 小图标。
- **排行榜**：表头主色渐变、行 hover 高亮、前三名名次徽章色。
- **日志/聊天/倒计时条**：统一令牌配色与滚动条样式。

## 5. 动效（适中）

- 保留：fadeIn、slideUp、splash-ripple、pulse。
- 新增：当前回合指示器呼吸辉光；命中格子短促爆闪（复用/扩展 `.cell.hit` 入场动画）；匹配倒计时条改为波纹流动渐变；按钮/卡牌微交互过渡统一 0.18–0.25s。
- 不做：全屏粒子烟花、强视差、长循环复杂动画。

## 6. JS 改动（最小化）

- `game.js`：仅 `initParticles` 视觉参数（气泡化、取主色）与主色选择器回调补设 `--primary-rgb`。其余逻辑零改动。
- `magic_cards.js`、`music_player.js`、`test_magic.js`：不改动。
- `index.html` 内联主题切换脚本：不改动。

## 7. 兼容与回归保障

- 所有 id 与功能 class 不变 → `game.js` DOM 钩子、`tests/` 下 Python 测试（作用于服务端/游戏逻辑）不受影响。
- 深浅主题均有完整令牌映射；自定义主色在两种主题下生效。
- 响应式断点（600/768/992/1200px）保留并适配新布局。

## 8. 测试计划

1. 启动本地服务器，浏览器逐屏检查：开始界面、自定义房间、布阵、猜拳、对局主界面（含日志/预览/聊天浮窗）、大厅、排行榜、结算、各弹窗。
2. 切换深色/浅色主题检查令牌完整性（无白底黑字错乱）。
3. 设置面板更换主色，确认按钮/高亮/`rgba(var(--primary-rgb),…)` 处同步变色。
4. 浏览器截图留档（开始界面、对局界面、深色模式）作为验收证据。
5. 运行现有 `pytest` 快速确认服务端逻辑无回归（预期零影响）。
