# 深海远征赛季通行证规格

## 已确认规则

| 项目 | 首季决定 |
|---|---|
| 周期 | 8 周，服务器按 `Asia/Shanghai` 计算日切与周切 |
| 等级 | 1～50 级，毕业累计 20,000 XP，经验自动入账 |
| 领取 | 奖励由玩家手动领取；赛季结束后保留 14 天领取宽限期，宽限期结束自动补发未领取奖励 |
| 豪华轨 | 首版只允许管理端/服务端受控授予，不接支付；获得资格后可补领已达等级的豪华轨奖励 |
| 计入对局 | 真人排位、真人休闲 |
| 排除对局 | 自定义房、AI、测试事件、观战、回放 |
| 赛季挑战 | 包含高要求或较多局数的挑战，挑战 XP 不能成为轻度玩家获得中段奖励的唯一入口 |
| 终点奖励 | 50 级提供一个赛季专属称号；徽章佩戴系统作为后续扩展 |

## 经验与等级

- 每日 3 个任务完成任意 2 个：200 XP。
- 每周 3 个任务完成任意 2 个：800 XP。
- 赛季挑战作为额外 XP 来源，使用服务端累计事实；不会读取客户端进度。
- 等级阈值由服务端 `battle_pass.py` 计算，客户端只显示服务端快照。
- 经验事件以 `(user_id, season_id, source_kind, source_id)` 去重；同一场对局、任务周期或挑战完成不能重复发放。

## 挑战目录

首版挑战使用可从结算事实可靠获得的累计指标：

| ID | 目标 | XP |
|---|---:|---:|
| `voyage_matches` | 完成 20 场真人排位或休闲 | 800 |
| `voyage_wins` | 获胜 10 场真人排位或休闲 | 1,000 |
| `card_cadet` | 真人对局累计使用卡牌 50 次 | 800 |

挑战进度和首次完成奖励均写入同一事务；AI、自定义房和测试事件不推进挑战。

## HTTP 契约

- `GET /api/battle-pass`：登录用户读取当前赛季、状态、XP、等级、奖励轨道、挑战、已领取记录和豪华资格。
- `POST /api/battle-pass/claim`：请求体 `{season_id, level, track}`；服务端校验领取窗口、等级、轨道资格和奖励目录，重复请求返回幂等结果。
- `POST /api/admin/battle-pass/grant-premium`：管理端受控授予豪华资格，首版不是支付接口。

## 隐私与兼容

赛季奖励写入 `user_cosmetic_rewards`，现有名片读写在服务端将其与普通解锁规则合并；未领取、未拥有的奖励不能通过客户端直接装备。新增表只追加数据，不改变既有任务、永久经验和对局历史口径。
