# 以 C 为起点的 UI 原型 · 2026-09-28

入口：`arena-next.html`。可直接双击，也可在本目录启动静态 HTTP 服务。

| 方案 | 入口 | 差异 |
| --- | --- | --- |
| X · C+ 精修竞技场 | x-arena-evolved.html | 紫金融合，保留三栏首页和常驻战术侧栏 |
| Y · 舰桥指挥台 | y-bridge.html | 深青／青铜、竖向导航、仪表与坐标风格 |
| Z · 专注竞技场 | z-focus.html | 单一主入口、双盘居中、战况简条 |

每个入口支持 `?view=game` 直达对局。页面底部可切换方案与视图，保留原 C 入口。

共用 `arena-next.css`、`arena-next.js`；无外部依赖。只增加静态示例，不替换正式 UI，不读写游戏数据。

可体验：难度选择、模式进入示例对局、卡牌详情弹窗、选格与确认攻击、排行榜／名片／大厅／对局记录示例。所有数值为固定样本；确认攻击固定演示未命中；结束回合仅提示；卡牌不执行规则。绘图使用本地 CSS 与 SVG 图形。

手机采用滚动布局，先显示目标海域，再显示己方海域，手牌横向滑动。尚未设计手机连锁操作。桌面同时展示两块等大海域，720px 高度使用紧凑布局。

验证：三方案 × 首页／对局 × 1440×900、1280×720、390×844，共 18 张截图；浏览器无 JS 异常，无页面横向溢出；桌面手牌完整在视口内；难度选择、详情弹窗、选格、确认攻击检查通过。截图存于 `shots/`。

复跑（使用独立端口以隔离浏览器 profile）：

```sh
node tools/ui_demo_shots.mjs --only x-arena-evolved --port 9364
node tools/ui_demo_shots.mjs --only y-bridge --port 9365
node tools/ui_demo_shots.mjs --only z-focus --port 9366
```

建议优先评估 X；允许组合方案，例如 X 首页 + Y 色彩 + Z 战况简条。选定后再接真实状态与卡牌流程。

## 周边屏幕 · 2026-09-29

入口：`arena-suite.html`，沿用 C+ 的紫金竞技场风格。左侧导航（手机为横向导航）和页面底部的上／下一屏连接以下 10 个界面；此前 X/Y/Z 的大厅、房间、排行、名片、图鉴按钮也已接入新页面。

| 屏幕 | URL 参数 | 可体验内容 |
| --- | --- | --- |
| 游戏大厅 | ?view=lobby | 房间状态筛选、搜索空态、房间号校验、加入与观战入口 |
| 好友房间 | ?view=room | 双方席位、准备、复制示例房间号、进入部署 |
| 舰队部署 | ?view=placement | 单格舰船放置／撤回、随机六格、清空、完成确认 |
| 魔法图鉴 | ?view=collection | 48 种不同卡名、关键词／类型／速阶筛选、桌面详情栏、手机详情弹窗 |
| 海域排行 | ?view=leaderboard | 前三名展示、指标切换、个人档案弹窗 |
| 指挥官档案 | ?view=profile | 段位与战绩、徽章佩戴预览、历史回放入口 |
| 对局结算 | ?view=result | 胜利／失败状态切换、积分与经验、回放入口 |
| 观战席 | ?view=spectate | 只读双海域、公开战报、隐藏未知船位 |
| 对局回放 | ?view=replay | 8 步固定事件、播放／暂停、倍速、前后步进、拖动时间轴 |
| 偏好设置 | ?view=settings | 强调色、音量数值、开关、高对比网格预览、减少动效 |

文件：`arena-suite.html`、`arena-suite.css`、`arena-suite.js`、`arena-suite-cards.js`。卡表来自 `static/magic_card.json` 的去重离线快照（50 条记录 / 48 种不同卡名）；不依赖 HTTP 拉取，可直接离线打开。

限制：全部为静态原型；示例船位不会带入原 X 对局，进入前有明确说明。设置只保留在当前页面内存中，不实际播放音频，不写入账号；回放是固定事件示意；没有真实匹配或聊天发送。图标与符号卡面用于视觉排版示意。

验证：10 屏 × 1440×900、1280×720、390×844，共 30 张截图；无页面横向溢出与 JS 异常。浏览器内检查房间筛选／空态／房间号、布船上限与撤回、卡牌规则详情与筛选、排行、徽章、胜负切换、只读观战、回放推进和设置往返状态。矮屏桌面部署按钮可见。手机长页面滚动浏览，排行榜表格局部横向滚动。

```sh
node tools/ui_demo_shots.mjs --only arena-suite --port 9371
```
