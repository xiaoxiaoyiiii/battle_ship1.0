用牌流程 · 两选一HOW A CARD GETS USED
示意稿 O

你问的「确认使用按钮到底好不好用」——把它拆成两条流程画出来，代价写清楚。 结论先说：不该一刀切，按"这张卡要不要选目标"分流，下面第三条是建议方案。

A · 再点一次即用

  • 1点卡牌 → 二级预览（抬起 + 右侧介绍）
  • 2再点同一张牌 → 直接打出
＋ 步骤最少，手指不用离开牌。
－ 需要选目标的卡（神威！/ 轰炸 / 增援 / 桃园结义）没法"再点即用"，得另开一条路径。
－ 误触即生效、且不可撤销：一张 速阶Ⅲ 的牌打空了，一回合就没了。

B · 选中后按「使用」按钮

  • 1点卡牌 → 二级预览
  • 2（需要目标的卡）在棋盘上点目标
  • 3按「使用 / 确认」→ 打出
＋ 明确、可撤销（点空白或"取消"即回退），所有卡流程一致。
＋ 需要选目标的卡本来就要多一步，按钮只是把这一步"说出来"。
－ 不需要目标的卡也得多按一次；按钮若在远端角落，目光要来回跑。
建议方案 · 按卡的类型分流（推荐）

C · 无需目标的卡：再点即用；需要目标的卡：选完目标后确认 推荐

卡需要目标？流程为什么
失灵！（无效上一张）否点两次即用意图唯一，没有歧义，也就没有确认的必要
看破！（大回合内全无效）否点两次即用同上；这类卡是"连锁里的应急牌"，越快越好
神威！（3×3 除外）是点选 → 棋盘点区域 → 确认点错 3×3 的代价太大；确认按钮同时充当"目标已选好"的反馈
轰炸（整行/列）是点选 → 棋盘点行/列（整行高亮）→ 确认整行是 6 格，误触代价大
增援 / 死者苏生（选格放置）是点选 → 棋盘点格子 → 确认放置类，确认前可以改格子
＋ 快牌更快（应急牌两步到底），慢牌更稳（选目标后确认）。
＋ 按钮的文案随状态变：未选目标时显示「在棋盘上选区域…」且置灰，选好后变成「确认使用 神威！」——按钮本身就在告诉玩家下一步。
－ 代价：两条流程并存，需要一次简短的首次引导（或在那张卡上加个"点击选目标"的角标）。
