# 战舰棋前端视觉优化提案

状态：用户于2026年10月26日批准整套方案，开始实施。原始样图位于仓外 `D:/Codex workspace/battle-ship-ui-proposal-20261026`；基点为已推送的 `89caf15`，沿用 `review/main-ui-vue-port` 分支。

## 推荐方向

沿用现有深海竞技场风格，把重点从密集边框和背景放射纹转向棋盘与真实卡面。深蓝为底，蓝灰边线区分面层；紫色只强调主操作和选中态，青色表示己方，珊瑚红表示对手，金色用于连锁、场地和荣誉。

建议色板：背景 `#0b1120`、面板 `#111c2e`、描边 `#26364d`、主操作 `#a990f5`、己方 `#61c7d8`、金色 `#debd79`。沿用系统中文字体，以字重和间距建立层级；正式实现的正文以14–15px为主，辅助说明保留可读字号，并验证“大/特大”设置。

## 交互与布局约定

- 动画仅用透明度和位移反馈展开、切换、悬停，尊重减少动效设置。
- 场地栏固定占位，1/2/4块并列；数量变化不推动棋盘。
- 右侧连锁、操作和统计各自占位；长连锁内部滚动。更多操作作为浮层展开。
- 弹层标题与关闭按钮保持可见，预览根据鼠标、可用空间与视口边缘避让。
- 手机沿用现有海域切换，正文优先可读、按钮保持触控尺寸；不通过整体缩放桌面界面适配。
- 正式实现时优先整理同一组件和断点的有效规则，避免继续在样式文件末尾叠加冲突覆盖。
