# 战舰棋宣传 CG 成熟项目调研与最终修订方向

日期：2026-10-30。用途：为《战舰棋：深海作战室》90 秒宣传 CG 做最后一轮叙事和剪辑修订。

## 一、这轮调研关注什么

本轮不复制成熟游戏的画面、角色或音乐，只抽取它们在宣传 CG 中反复使用的结构：

1. 前几秒如何给观众一个必须继续看的问题；
2. 如何用一个角色或明确视角承载情绪，而不是只堆系统界面；
3. 如何让音乐、镜头和动作一起完成高潮；
4. 如何在情绪之后把真实玩法和产品入口交代清楚；
5. 如何让片尾的游戏名和行动入口成为前面叙事的自然结果。

## 二、成熟项目的可借鉴做法

### 1. Overwatch：先让观众关心“谁”，再让观众关心“发生了什么”

暴雪在介绍 Overwatch 动画短片时明确强调：短片时长有限，不能依赖长篇世界观说明，需要把情绪、角色关系和环境压缩进少量镜头；视觉开发从概念草图、分镜、灯光和构图一起服务情绪，音乐再和画面反复对齐。[Overwatch 官方幕后文章](https://overwatch.blizzard.com/en-us/news/23686849/cinematic-magic-inside-the-visuals-and-music-of-overwatch-shorts/)

对战舰棋的启发：宣传片不能只有“棋盘很漂亮”。应该把观众固定在一个玩家视角里，让他先看到“我方只剩一艘船、对手的卡马上要结算、还有一次响应机会”，再展开玩法。这样卡牌和 UI 就是角色行动的语言。

### 2. Overwatch：用“冲突 → 希望 → 选择”替代功能罗列

Overwatch 官方回顾初代动画时提到，开场先制造危机和失序，再引出英雄与希望；开发团队用角色需要、关系和世界状态作为故事的北极星，而不是把所有设定一次讲完。[Overwatch 官方导演文章](https://overwatch.blizzard.com/en-gb/news/23977044/director-s-take-the-next-chapter-in-the-story/)

对战舰棋的启发：长版 CG 的第一段可以直接从“对方高阶卡进入结算、我方只剩一艘战舰”开始，接着切回布船和猜拳，形成“危机先行、规则补充、反制翻盘”的结构。观众先想知道能不能救回来，再愿意看懂规则。

### 3. VALORANT：用一个明确的能力承诺，让玩法信息容易记住

VALORANT 的官方主站在介绍游戏时用角色定位和能力承诺组织信息，例如控制战场、追踪、禁用、防守等，而不是只说“有很多内容”；官方同时把纯剧情 CG、地图预告和 Cinematic Gameplay Trailer 分成不同用途。[VALORANT 官方主站](https://playvalorant.com/en-us/console/)

对战舰棋的启发：宣传片中不要平均展示 48 张卡，而是选三种记忆点：

- **改变空间**：神威/区域效果；
- **改变结算**：失灵/连锁反制；
- **改变胜负条件**：绝处逢生或场地魔法。

每一种只用一个动作和一句短字幕说清楚，观众会记住“这款游戏能改写规则”，而不是记住一长串卡名。

### 4. VALORANT：纯 CG 与玩法展示分工，不能互相冒充

VALORANT 官方页面同时列出纯 Cinematic Trailer、Cinematic Gameplay Trailer 和 Dev Diary，说明成熟项目会把情绪叙事、玩法证明和开发说明分开承担。[VALORANT 官方主站](https://playvalorant.com/en-us/console/)

对战舰棋的启发：本片采用“实机 UI + 电影化镜头运动”的混合方式，不伪造一段不存在的 3D 舰队战斗。镜头可以对真实棋盘、卡牌、连锁画面做推拉、景深、遮罩和速度变化，但每个关键规则都必须来自真实页面。

### 5. GDC：先找差异化信息，再决定镜头

GDC 的《More Feelings, Fewer Features: Showcasing Your Indie Game Through Messaging and Video》把“情绪和差异化信息”放在“展示更多功能”之前，重点是让视频先讲清楚观众为什么要记住这个游戏。[GDC 官方演讲条目](https://gdcvault.com/play/1026445/More-Feelings-Fewer-Features-Showcasing)

对战舰棋的启发：本片的核心句不改成“48 张卡、实时对战、完整回放”，而是继续围绕：

> **每一格都可能是陷阱，每一张牌都可能改写胜负。**

功能只作为这句话的视觉证据出现。

### 6. Bungie：音乐是发布动作的一部分，不只是背景

Bungie 在 Marathon 上线公告中把 Launch Cinematic、原创音乐、上线时间、平台和可获得内容放在同一个发布节点里；音乐不是最后才贴上的背景，而是帮助形成记忆点和发布动作的主线。[Bungie 官方上线公告](https://origin-static01.bungie.net/7/en/News/Article/marathon_launches_tomorrow)

对战舰棋的启发：为本片设置一个可反复出现的“声纹记忆点”：开场是一声远处声呐定位，连锁前短暂抽空音乐，反制成功时同一声纹转成更明亮的金属回响，片尾再回到声呐音。这会比单纯堆十几种效果音更容易留下印象。

## 三、对现有脚本的最终修改

### 修改 A：开头从“提问”升级为“危机中切入”

原来的 0–4 秒是黑场网格和“你以为，这只是战舰棋？”。保留这句，但在它之前加入 0.8–1.2 秒的危机闪现：连锁栈中高阶卡即将结算、己方只剩 1 艘船、倒计时进入最后一拍。随后瞬间切黑，再出现问题句。

这样沿用成熟 CG 的“先让观众想知道结果，再补充世界规则”，同时不改变项目真实玩法。

### 修改 B：把玩家身份提前到匹配成功段落

匹配成功不只展示两块身份卡，要让“管理员01/玩家称号/头像框/段位”成为主角第一次出现的正脸。对手只保留轮廓、AI 标识和一张高阶卡，避免过早展示全部信息。

### 修改 C：连锁段落加入“静音半拍”

连锁前保留 6–8 帧几乎无音乐的空白，只留下卡牌滑入和呼吸声；玩家打出反制时让 UI 亮度、金属撞击和低频一起回归。音乐和镜头在同一个动作上落点，增强“我救回来了”的感受。

### 修改 D：减少后半段功能清单，增加一个完整微故事

将 01:20–01:27 的“大厅、邀请链接、图鉴、观战、主题设置”压缩为 3 个切片：

1. 结算页点击回放；
2. 回放拖到连锁翻盘节点；
3. 个人名片的称号/头像框/背景和一键邀请。

这样结尾仍然展示长期内容，但不让宣传片突然变成菜单导览。

### 修改 E：片尾 CTA 和开头声纹闭环

片尾先回到开场的 6×6 网格，再出现“立即开战”。旁白不再重复功能，而是说：

> **下一次翻盘，由你决定。**

声呐定位音在这里回归，形成可识别的音频首尾闭环。

## 四、最终制作原则

- 前 5 秒给结果问题，前 20 秒让观众看懂基本循环；
- 一条宣传片只讲一个核心差异：卡牌能改写海战棋的结算；
- 角色感来自玩家的身份、剩余船数和选择压力，不需要伪造角色对白；
- 真实 UI 负责证明玩法，电影化镜头负责控制情绪和节奏；
- 音乐在连锁前留白、在反制时回归，避免全片同一强度；
- 个性化内容在后半段集中出现一次，服务“这是你的战局”；
- 片尾必须有明确的“立即开战”动作入口，而不是只放 Logo。

## 五、来源与边界

本轮调研只借鉴结构、节奏、情绪组织、音乐配合和产品信息表达，没有下载、复制或使用上述项目的角色、镜头、音乐、贴图和视频素材。所有战舰棋镜头仍需从当前实机或项目已有合法素材中获得。
