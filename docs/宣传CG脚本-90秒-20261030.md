# 《战舰棋：深海作战室》90 秒宣传 CG 脚本

版本：V1.0（脚本阶段）
日期：2026-10-30
用途：首发宣传片 / 商店页首屏 / 社交平台横版短片

## 一、影片定位

这不是功能列表视频，而是一场在 90 秒内完成的“微型战局”。观众先看到熟悉的 6×6 海战棋，再迅速发现它被 48 种魔法卡、连锁响应、段位身份和动态个人化内容重新改写。

核心承诺：

> **每一格都可能是陷阱，每一张牌都可能改写胜负。**

影片不虚构尚未实现的功能，不把所有界面逐页扫过；只展示当前已经存在且能在实机中录到的内容：大厅、匹配、布船、猜拳、战斗棋盘、卡牌连锁、AI、人机/排位身份、个人背景与指针效果、结算和回放。

## 二、成片规格

| 项目 | 设定 |
| --- | --- |
| 总时长 | 90 秒左右，可剪成 30 秒预告版 |
| 画幅 | 主版 16:9，后续从安全区裁 9:16 |
| 节奏 | 0–8 秒抓人，8–35 秒讲清玩法，35–68 秒连续升级，68–82 秒展示身份与回看，82–90 秒品牌收束 |
| 视觉 | 深海蓝黑为底，青色己方信息，紫色主操作，金色稀有/连锁重点 |
| 音乐 | 低频深海氛围 → 电子脉冲 → 连锁段落加入金属打击 → 结尾留一拍空白后落 Logo |
| 声音 | 优先使用项目已有 Web Audio 音效和卡牌专属音；重要事件保留点击、匹配、连锁、命中、胜负反馈 |
| 旁白 | 中文男/女声均可，低声压、克制、像战术播报；字幕必须独立成立，静音观看也能看懂 |

## 三、逐镜头脚本

### 00:00–00:04｜黑场起航：先抓住眼睛

**画面**：纯黑中出现一条细窄的青蓝光线，像海面上的坐标线。光线迅速扩成 6×6 网格，远处有低频波纹和星点漂移。不要直接从首页静态截图开始。

**声音**：低频水下轰鸣，随后一声短促金属定位音。

**字幕**：

> 你以为，这只是战舰棋？

**旁白**：

> 你以为，这只是战舰棋？

### 00:04–00:10｜棋盘亮相：熟悉规则，陌生压力

**画面**：镜头俯冲进入真实对局棋盘。两侧 6×6 海域由空到满，六艘单格战舰逐一亮起；坐标、剩余船数、攻击次数快速出现。镜头不要停留在整个 UI，先用棋盘和舰船建立识别。

**声音**：六次轻微布船落点音，最后一声更低沉。

**字幕**：

> 6×6 海域 · 6 艘战舰 · 猜拳定先手

**旁白**：

> 藏好你的舰队，猜拳决定谁先开炮。

### 00:10–00:18｜魔法卡登场：从海战棋切入卡牌对决

**画面**：手牌从屏幕底部推入，快速切换 4 张代表卡面：神威、轰炸、仁王之盾、教皇旨意。每张卡只给 8–12 帧主视觉，避免观众来不及看清又造成拖沓。卡面文字只保留关键词。

**声音**：抽卡音 → 四种短卡牌提示音，节拍与剪辑点对齐。

**字幕**：

> 48 种魔法卡

**旁白**：

> 这里的胜负，不只靠运气。

### 00:18–00:29｜第一轮战术：让观众马上看懂“怎么玩”

**画面**：玩家在己方准备阶段选择卡牌，目标框锁定对方 3×3 区域；镜头切到对方棋盘，区域内的战舰短暂消失，留下空间扰动。紧接一个普通开炮格子，命中后出现局部反馈。

**声音**：目标选择轻音 → 神威空间扭曲 → 命中音。

**字幕**：

> 选牌 · 选区 · 开火

**旁白**：

> 选一张牌，改变一片海域，再用炮火逼对手暴露。

### 00:29–00:41｜连锁响应：全片第一个真正的高潮

**画面**：对手打出一张高阶卡，画面瞬间压暗。卡牌沿纵深叠入中央连锁栈，第一张牌展开；玩家的速阶 3 卡从侧面切入，像刀锋一样截断原本的结算路径。画面只保留后进先出的关键两到三层，不展示复杂日志。

**声音**：音乐节拍短暂停顿，接链提示音、金属撞击、低频反制音依次叠入。

**字幕**：

> 对手出牌，不代表结算结束。

**旁白**：

> 对手出牌，不代表结算结束。

### 00:41–00:52｜反制翻盘：让观众产生“我也想试”

**画面**：玩家打出“失灵！”或同类反制卡。连锁栈从下到上被压回，原本即将击沉的舰船在护盾/状态效果中留下残光；随后快速切三种效果：冻结区域、整行轰炸、护盾破碎。每个效果只展示动作完成，不解释全部规则。

**声音**：反制音突出，命中/冻结/护盾破碎分别做短促辨识；音乐进入更密的鼓点。

**字幕**：

> 一张牌，改写整个回合。

**旁白**：

> 一张牌，改写整个回合。

### 00:52–01:02｜大师 AI 与实时对战：告诉观众“对手不会木桩

**画面**：快速交叉剪辑两条路径：

1. 大师 AI 看向手牌候选，选择一张信息卡后锁定目标；
2. 真人匹配成功界面，双方身份卡片、段位、头像框和倒计时在屏幕中央对撞。

**声音**：匹配成功提示 → 倒计时三拍 → 轮到行动的确认音。

**字幕**：

> 大师 AI · 休闲匹配 · 排位对战

**旁白**：

> 想练习，有会思考的对手；想证明自己，就进入实时对战。

### 01:02–01:12｜你的身份：让游戏不只是一块棋盘

**画面**：从战斗 HUD 的头像和头像框拉近，转场进入个人名片。展示三种不同的个人背景层：海图网格、潮汐光晕、星点漂移；称号出现一次短暂高光，鼠标移动留下尾迹，点击头像框产生一次波纹。镜头只展示局部细节，不把动效铺满整个画面。

**声音**：音乐进入更有空间感的段落；轻微 UI 点击音和个性化特效音作为近景细节。

**字幕**：

> 你的舰队，也有自己的旗帜。

**旁白**：

> 头像框、称号、背景和动态效果，让每一次登场都留下你的痕迹。

### 01:12–01:20｜胜负与回放：给出长期玩的理由

**画面**：胜负结算不是简单“胜利”大字，而是快速扫过本局关键节点、最高连锁、命中与船数变化；镜头接到回放时间轴，拖动一个关键节点，棋盘状态回到翻盘瞬间。

**声音**：胜利音短促收束，回放拖动使用轻微时间扫描声。

**字幕**：

> 每一局，都值得回看。

**旁白**：

> 赢下这一局，也留下下一局的答案。

### 01:20–01:27｜多种入口：降低第一次游玩的门槛

**画面**：大厅房间列表、复制邀请链接、卡牌图鉴、观战入口、主题设置以四到五个快速切片出现。不要完整展示设置页面，只让观众确认“进得来、玩得懂、看得回”。

**声音**：按钮点击和翻页音按节拍连续出现，最后一个切片静音半拍。

**字幕**：

> 不注册也能开局 · 邀请好友 · 回放复盘 · 实时观战

**旁白**：

> 现在就开一局，下一次翻盘由你决定。

### 01:27–01:30｜品牌落版：留一个记忆点

**画面**：所有 UI 元素退入深海，6×6 网格重新出现。两条代表性光线在中心交汇，Logo 与项目名出现；右下保留“立即开战”按钮样式。最后一帧留 12 帧静止，方便平台截取封面。

**声音**：音乐完全停下后，留一声低沉而清晰的舰鸣；最后一拍是短促确认音。

**字幕**：

> 战舰棋 · 深海作战室
>
> 一格藏舰，万局博弈。

**旁白**：

> 战舰棋。现在，进入深海作战室。

**CTA**：

> 立即开战

3. 00:29–00:52 连锁反制与翻盘；

## 五、实际录制清单

### 必须重新录制的实机镜头

- 一局完整的准备→猜拳→战斗流程，保证录制时序自然；
- 一次真实连锁：对手出牌、玩家响应、成功结算；
- 神威/轰炸/冻结/护盾四类效果的干净单镜头；
- 大师 AI 使用魔法卡并完成一次攻击；
- 匹配成功中央身份卡与倒计时；
- 个人名片背景、头像框、称号、全局尾迹和点击波纹；
- 胜负结算进入回放并拖动到关键节点。

### 录制注意事项

- 录制版关闭浏览器扩展、桌面通知和不属于游戏的壁纸控件；
- UI 录制用 2560×1440，游戏画面安全区留 8%；
- 关键卡牌和连锁必须单独录制干净素材，后期再叠旁白和字幕；
- 旁白字幕不依赖颜色，所有重要信息同时有文字；
- 个性化特效只在资料页和身份展示段落集中出现，对局主体保持可读；
- 不把测试账号、内部日志、调试按钮或后台数据剪进成片。

## 六、剪辑验收标准

- 前 4 秒能说明“这不是普通战舰棋”；
- 35 秒前观众能看懂“布船、出牌、开炮、响应”的基本循环；
- 连锁翻盘是唯一最长高潮，不能被其他特效抢掉；
- 个人化内容出现一次即可记住，不能变成装饰展示合集；
- 静音播放时，字幕仍能完整表达玩法和 CTA；
- 片尾至少保留 12 帧静止 Logo，便于平台封面和短视频截帧；
- 成片只使用当前实机可验证的功能，不使用概念稿冒充已实现内容。
