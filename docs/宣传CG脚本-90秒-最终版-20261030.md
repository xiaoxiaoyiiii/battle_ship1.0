## 一、终审判断：V1 还有六处像“功能介绍片”

V1 的骨架是对的（危机—规则—连锁—身份—回放—CTA），但落地文字里仍留着三样“产品说明书”的痕迹：**用旁白复述字幕**、**用段落数量代替情绪层次**、**用功能条目收尾**。逐条如下：

| # | 位置 | 病症 | 观众实际感受 |
| --- | --- | --- | --- |
| 1 | 00:00–00:04 | 悬念是修辞悬念（自问自答），不是情节悬念 | “又在铺垫”，快进 |
| 2 | 全片 | 没有一个人称视角；“你”只出现在旁白里 | 看的是 UI，不是一场战局 |
| 3 | 00:10–00:18 | 4 张卡面 8–12 帧快切 = 卡表导览 | 记住“卡很多”，记不住任何一张 |
| 4 | 00:29–00:52 | 连锁与翻盘被拆成两段高潮，52 秒又叠匹配音效 | 高潮平了，没有峰值 |
| 5 | 01:02–01:27 | 身份 + 回放 + 入口三段并列 = 功能清单 | 后半段像商店页轮播 |
| 6 | 01:27–01:30 | CTA 是字幕 + 按钮贴图 | 结尾是“贴上去的”，不是打出来的 |

修订原则一句话：**一条片只讲一个差异，一个动作只给一次峰值，其余全部让路。**

## 二、六项最终修改（修改前 → 修改后 → 理由）

### A1 开场钩子：把“提问”换成“残局最后一拍”

- **修改前**：00:00–00:04 黑场 → 青蓝坐标线扩张成 6×6 网格 → 字幕与旁白同文“你以为，这只是战舰棋？”
- **修改后**：
  - 00:00–00:01.2 **先给结果**：真实残局特写——我方剩余舰数显示 `1`、对手一张速阶 3 卡正压在连锁栈顶、连锁窗口倒计时只剩 `3 → 2 → 1`。画面同时压暗、边缘失焦，只留这三处可读信息。
  - 00:01.2 一声金属过载音把画面**切黑**（不是淡出，是硬切，留 6 帧纯黑）。
  - 00:01.4 黑场里坐标线从中央单点亮起并扩成 6×6 网格，问题句此时才出现：“**只剩一艘船，你还有一次机会。**”
  - 00:03.6 网格向镜头推进，直接穿进对局（承接 A2）。
- **理由**：成熟 CG 先让观众想知道“救回来没有”，再补世界规则。V1 的问题句是修辞；改后的第一帧是**可被记住的具体处境**（1 艘船 + 倒计时），而且这个处境 100% 来自实机：连锁窗口、剩余舰数、连锁栈都在当前对局里可录。

### A2 玩家视角：给“你”一个颜色锚点，并让它贯穿前 20 秒

- **修改前**：镜头在棋盘、手牌、卡面之间游移，靠旁白说“藏好你的舰队”。
- **修改后**：
  - 全片统一两个颜色锚点：**青色 = 你**（己方海域、己方 HUD、己方手牌），**琥珀金 = 对手的威胁**（对方连锁牌、对方命中）。
  - 00:04–00:10 布船段固定一个“你的手在放船”的主观机位：六格依次落位，最后落位时画面轻微下沉，HUD 的“剩余 6 艘”跟着跳一次。
  - 00:18–00:29 选区段，先给“你”的手牌被推出、再给“你”选的 3×3 区域在**对方**海域亮起（青色描边压在对方棋盘上），构图让观众知道“这是我的操作，打在他那边”。
  - 旁白只在这一段出现一次：“**你的舰队，只有你知道它在哪。**”
- **理由**：清晰玩家视角靠的不是旁白人称，而是**颜色与机位的所有权**。这正是验收里“一个清晰的玩家视角”的落点，且所有元素都是实机已有：己方/对方海域配色、序号与剩余舰数、区域选区预览。

### A3 魔法卡：从“4 张卡表”改成“3 个能力承诺”

- **修改前**：手牌推入后 4 张卡面各 8–12 帧快切（神威、轰炸、仁王之盾、教皇旨意），字幕“48 种魔法卡”。
- **修改后**：只留 3 张，每张绑一个**结果动作**，单张 24–30 帧，字幕各 2 字：

  | 卡 | 镜头里的结果动作 | 字幕 | 承诺 |
  | --- | --- | --- | --- |
  | 神威！ | 对方 3×3 区域亮起，区内舰船原地消失留空间扰动 | **改空间** | 棋盘本身会变 |
  | 失灵！ | 连锁栈顶牌被一道横切光压回去，结算箭头折返 | **改结算** | 出牌不等于生效 |
  | 绝处逢生 | 我方满盘舰船清空，只剩一格孤舰亮起 | **改胜负** | 剩一艘也可能赢 |

  “48 种魔法卡”这句字幕挪到 A5 的连锁高潮之后，作为高潮的注脚，而不是开场卖点。
- **理由**：48 是数量，观众记不住；三类“能改写什么”是承诺，观众能复述。三张卡都在当前牌表与效果实现里存在，且都能录到干净单镜头。

### A4 连锁：合并成唯一主高潮，52 秒不再叠音效

- **修改前**：00:29–00:41 连锁（第一高潮）+ 00:41–00:52 翻盘（第二高潮）+ 00:52–01:02 匹配（第三段密集音效）。
- **修改后**：把 29–52 合成**一段 23 秒的单一高潮**，内部三层递进，不给新主题：

  - 29.0–31.0 **压暗**：对手速阶 3 卡入栈，音乐掉到只剩低频心跳与一声卡牌滑入。
  - 31.0–31.4 **留白半拍**（6–8 帧音乐几乎消失）：只留 UI 悬停与一次呼吸。
  - 31.4–36.0 **第一层**：你的速阶 3 从侧下方切入，截断结算路径；卡牌沿纵深压回一格，金属撞击与低频同时回归。
  - 36.0–43.0 **第二层**：对手再反制，画面二次压暗但**不加新音色**，只把同一金属动机升半音；你的“失灵！”把栈顶压平，画面亮度回升。
  - 43.0–48.0 **结果落地**：冻结区域结霜 → 整行轰炸扫过 → 护盾破碎三道短切，每道 0.8 秒，节奏同拍。
  - 48.0–52.0 **喘息**：结算完成，棋盘恢复正常亮度，只剩 HUD 数字跳动；音乐第一次留出完整一小节空白。
- **理由**：峰值只允许一个。把“翻盘”并入连锁的第二层，观众感受到的是**同一场对抗的升级**，而不是两条并列的卖点；52 秒处留出让 AI/匹配段自然降为叙事过渡。

### A5 后半段：三段功能 → 一条微故事 + 两个证据镜头

- **修改前**：01:02–01:12 身份（头像框/称号/背景/尾迹/波纹）、01:12–01:20 胜负与回放、01:20–01:27 多入口（大厅/邀请/图鉴/观战/主题）。
- **修改后**（压缩到 01:00–01:24，腾出的 2 秒还给连锁）：

  - 01:00–01:09 **「这是你的战局」一镜完成**：从对局 HUD 的头像框拉近 → 转场进个人名片（背景层依次被读到：网格、极光、星点、同心环）→ 指针划过留下 480ms 尾迹 → 点击头像框出一次波纹 → 称号徽章亮一次高光后恢复。**全部在同一个镜头运动里完成，不切页。**
  - 01:09–01:16 **回放即答案**：结算页停留 0.8 秒（只读“最高连锁/命中数/船数变化”三行）→ 点进回放 → 拖动时间轴到连锁翻盘那一帧，棋盘倒回 A4 的 31.4 秒状态。
  - 01:16–01:24 **两个入口切片**：①大厅“复制邀请链接”被点击、链接气泡浮出；②实时观战画面切一秒（双棋盘 + 观战条）。**图鉴与设置不做镜头**，只允许在邀请链接气泡的背景里被虚焦带过。
- **理由**：后半段的功能条目越多，前面的高潮越像“功能片的前奏”。身份段用一次连续运动证明“个性化能进入战局”，回放段用一次拖动证明“这局值得回看”，入口只留**邀请**与**观战**两个真正能降低门槛的动作。以上全部可在实机录到：大厅邀请链接、观战页、回放时间轴、个人名片与全局指针效果。

### A6 片尾 CTA：让按钮成为动作的结果

- **修改前**：UI 退入深海 → 网格重现 → 两道光交汇 → Logo + 项目名 + “立即开战”按钮贴图 → 字幕并列游戏名与“一格藏舰，万局博弈”。
- **修改后**：
  - 01:24–01:26 回到 A4 的最后一炮：**一发命中落格**，红色命中标记在对方棋盘亮起（这是全片唯一一次“你打中”的干净结果）。
  - 01:26–01:28 命中波纹扩散成 6×6 网格，网格中心浮出“立即开战”（真实按钮样式，可点态高亮一次）。
  - 01:28–01:30 Logo 与“战舰棋 · 深海作战室”落版；字幕只留一行 CTA：“**下一次翻盘，由你决定。**”最后 12 帧静止（保留平台截帧安全区）。
  - 声纹闭环：开场那声金属过载在此转成一声清亮舰鸣，尾音收在 Logo 落点后 4 帧。
- **理由**：CTA 若只是贴图，观众记住的是排版；让“开炮命中 → 网格 → 按钮”成为同一动作的延续，按钮才是**结果**。同时满足静音可读：画面本身讲完了“打中—开战”。

## 三、旁白与字幕：从“同文复述”改成“分工”

V1 每一段都把旁白与字幕写成同一句，等于说了两遍。修订后：

- **字幕讲规则与结果**（可独立成篇，静音可读）；
- **旁白讲情绪与选择**（不重复字幕文字，允许留空）。

全片旁白压缩到 5 句（V1 为 9 句）：

| 时间 | 旁白 | 字幕（同期） |
| --- | --- | --- |
| 00:01.4 | 只剩一艘船，你还有一次机会。 | 6×6 海域 · 6 艘战舰 |
| 00:20 | 你的舰队，只有你知道它在哪。 | 选牌 · 选区 · 开火 |
| 00:31 | （无旁白，留白） | 对手出牌，不代表结算结束 |
| 00:44 | 一张牌，改写整个回合。 | 改空间 · 改结算 · 改胜负 |
| 01:28 | 下一次翻盘，由你决定。 | 战舰棋 · 深海作战室 |

**删掉的旁白**：猜拳说明、48 种卡数量、AI 与匹配的解释、身份段的四件套罗列、入口段的四行卖点——这些改由画面与两个字幕承担。

## 四、声音设计：一个声纹，三次变形，两处留白

- **声纹（Sonar Motif）**：开场金属过载 → 连锁第一层金属撞击（升半音）→ 片尾清亮舰鸣。同一动机三次变形，不新增主题。
- **两处留白**：31.0–31.4（6–8 帧近乎无声）、48.0–52.0（完整一小节空白）。留白是让峰值成立的成本，不能省。
- **可用素材**：`frontend/src/audio/assets/` 现有 33 个 wav（`bombardment`/`dark_pact`/`divine_banish`/`dice`/`discard`/`draw`/`electric`/`fire` 等）直接对齐剪辑点；卡牌专属音按卡名取用，缺失的用同类效果音替换，不新录外部音源。

## 五、转场与镜头语言：三种手法循环，不再“全片硬切”

| 转场 | 用法 | 出现次数 |
| --- | --- | --- |
| 网格扩张 / 收束 | 黑场↔对局、命中→片尾 CTA | 3 |
| 卡面遮罩（卡面推近填满画面再拉开） | 手牌段→对局、连锁段→AI 段 | 2 |
| 深海下潜（画面下沉 + 轻微失焦） | 身份段→回放段 | 1 |

**禁止清单**（避免回到功能片）：不做全屏图鉴网格、不扫设置页、不展示调试按钮/测试账号/内部日志、不并列四行卖点字幕、不在连锁段叠第二种音效主题。

## 六、录制清单（逐条对应真实可录功能）

| 镜头 | 实机入口 | 备注 |
| --- | --- | --- |
| 残局特写（1 艘船 + 连锁倒计时 3→1） | 对局内连锁窗口 + HUD 剩余舰数 | 用真实对局打到残局，不用夹具 |
| 布船六连落位 | 布船页（`placement`）随机摆放后逐格确认 | 录一次自然时序 |
| 3×3 选区预览 | 对局内神威！选目标（区域预览层） | 青色描边压在对方棋盘 |
| 连锁三层 | 真实双人对局：速阶 3 入栈 → 响应 → 再反制 | 必须真机 Socket 流程，不用动画占位 |
| 冻结 / 轰炸 / 护盾破碎 | 对局内对应卡结算 | 各录一条干净单镜头 |
| 大师 AI 出牌 | 人机对战（大师） | 只取“AI 选卡→锁定”一镜 |
| 身份三件套 | 个人名片（背景层）+ 全局指针效果 + 称号徽章 | 一镜连拍，不切页 |
| 结算 → 回放拖动 | 结算页 → 回放时间轴 | 拖到连锁那一帧 |
| 邀请链接 | 大厅自有房面板「复制邀请链接」 | 点击后链接气泡浮出 |
| 观战一秒 | 观战页 | 双棋盘 + 观战条 |
| 片尾命中 + 网格 + CTA | 对局命中 → 网格重现 → 按钮高亮 | 与开场同一张棋盘，形成闭环 |

录制规格沿用 V1：2560×1440、安全区 8%、关扩展与通知；关键卡面与连锁单独录干净素材。

## 七、时长分配对照（V1 → V2）

| 段落 | V1 | V2 | 变化 |

| 开场钩子 | 0–4s | 0–3.6s | 危机先行，问题句后置 |
| 棋盘与规则 | 4–10s | 3.6–10s | 加颜色锚点 |

## 十、仍未解决与风险

1. **残局录制可控性**：开场需要“我方剩 1 艘 + 对手速阶 3 待响应”的真实残局，人工打出来有随机性；建议录制时用对局内既有流程反复试到该状态，**不使用调试事件伪造**。
2. **区域预览与连锁窗口的录制帧率**：两者都是短动画（480–620ms），录制需 60fps 并在剪辑里做 0.5× 慢放补帧。
3. **旁白语言**：本稿按中文男声“战术播报”写；若改女声，A1/A4 两句需重新断句（建议仍保持短句 + 句中留白）。
4. **9:16 裁切**：A4 的连锁栈偏纵向，安全区裁切后栈顶卡面可能被切，需在录制时给连锁栈预留 12% 上留白。
