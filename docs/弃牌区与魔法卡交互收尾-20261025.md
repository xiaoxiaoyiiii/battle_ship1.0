## 一、弃牌区（本轮新增）

改造前：`frontend/src/screens/game/GameScreen.vue` 的抽屉里只有一串卡名文字（`ul.game-discard-list`），
无卡图、无网格、无悬停预览、无效果详情，关闭按钮在顶部但抽屉整体压在顶栏下面。

现在：

- 抽屉内容改成真实卡图网格：`div.game-discard-grid`（`repeat(auto-fill, minmax(68px,1fr))`，手机 56px），
  每张牌 `button.game-discard-card` 内是 `img.game-discard-card__art`（`cardArtUrl(name)`，缺失时回退卡名占位）
  加 `span.game-discard-card__name`；沿用原来的 `get_discard_pile` 数据，没有新增契约字段。
- 悬停/键盘聚焦复用普通手牌的预览层：`previewCard` 计算属性在弃牌悬停时优先返回弃牌卡
  （从 `CARDS` 取完整描述），因此仍然是同一个 `[data-testid="game-card-hover-preview"]` 面板。
- 点击卡片打开固定层 `[data-testid="game-discard-detail"]`（`z-index: 90`，右下角、不参与布局），
  显示卡名、速阶/类型与完整效果描述，带自己的关闭按钮 `game-discard-detail-close`。
- 展开/收起用 `<Transition name="drawer">`（transform + opacity，220/180ms），不改变布局；
  关闭按钮 `z-index: 2`，抽屉 `z-index: 80` 且 `top: 72px` 让开 64px 顶栏。
- 抽屉仍是 `position: fixed`，开关时棋盘矩形不变（探针实测 `259,210 701x416` 前后一致）。

## 二、顺带修掉的阻塞缺陷（既有缺陷，非本轮引入）

1440×900 下右栏底部（`查看弃牌堆` / `更多操作` / `进入战斗阶段`）被手牌行盖住，真实鼠标点不到：

- 证据（修复前 `dsh-r5/diag_buttons.mjs`）：`game-piles hit=game-hand`、`game-more hit=game-hand`、
  `game-primary hit=game-hand-wrap`；几何 `arena-rail 974,210 180x636`、`game-hand-wrap 284,634 872x255`。
- 归因：把本轮前端改动 stash 回 HEAD 重建后几何逐字相同，说明是基点 `6beca6f` 之后就存在的布局缺陷。
- 原因：`.game[data-layout='wide'] .arena-rail` 用 `grid-template-rows: minmax(200px,1fr) auto auto` +
  `overflow: visible` + `margin-bottom: -220px`，内容比容器高时溢出到手牌行下面。
- 修法（`frontend/src/screens/game/game-screen.css`，`@media (max-height: 980px)` 内）：
  `grid-template-rows: minmax(0,1fr) auto auto`、`overflow: hidden`、`margin-bottom: 0`，并把连锁轨道
  `max-height: 132px`。修后 `game-piles / game-more / game-primary` 均 `hit=自己`，右栏高度收在中栏内（416px）。
