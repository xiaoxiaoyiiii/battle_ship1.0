# 教皇旨意弃牌交互优化

教皇旨意生效、本人处于战斗阶段时，桌面和手机均提供独立的“弃牌换攻击”按钮。无论当前是否已有攻击次数，入口都保留；无手牌时禁用。主行动仍是“进入结束阶段”，不再由弃牌功能替换。进入结束阶段仍遵守原有规则，需要先用完可用攻击次数。

弃牌面板可多选、全选、取消选择，显示已选张数及攻击次数变化；一次确认完成整组弃牌，不再跳到卡牌详情窗逐张确认。取消不消耗手牌；提交中禁止重复确认。手牌在选取过程中变化时清空旧选择，避免索引错位。

`papal_discard` 增加可选字段 `discard_card_indices: number[]`，采用同一次请求到达时的手牌索引。空选择、重复索引、非整数或越界索引整体拒绝，任何一项无效均不弃牌、不增加攻击。校验后按索引倒序移除，每张仍增加 2 次攻击，弃牌事件与对局日志逐张保留。旧字段 `discard_card_index` 和未传索引时默认第一张的行为继续兼容；不改事件名或通用信封结构。

响应保留 `discarded`、`attacks_remaining`、`message`，补充 `discarded_cards` 和 `discarded_count`。客户端只使用成功状态，后续手牌与额度仍由服务端同步。

宽屏可拖动详情窗首次位于左侧聊天/日志栏旁，避开常驻浮窗和右侧阶段操作；用户拖动后的位置保留到本次页面结束。手机维持原有详情阅读面板。

回归资产在仓外 `D:/develop/battleship-verify/cases/papal-ux-20261103/`，包括批量校验与旧入口兼容、真实双人对局、手机尺寸、重复提交、取消和阶段切换验证。
