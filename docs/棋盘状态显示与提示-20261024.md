# 棋盘状态显示与提示

## 本轮实现

- 炮击落空：灰蓝格、空心圆与水面涟漪。
- 舰船命中／沉没：红格白叉，船形弱化在叉号下方。
- 护盾挡炮：金色破盾，与红叉区分；不表示当前仍有护盾。
- 护盾保护：青色完整盾与船形。
- 己方陷阱：紫色警戒三角；与护盾并存时保留角标。
- 合法待选格：绿色虚线框；选中区域与格子叠加绿色实框及勾号，保留原命中与护盾图案。

只给护盾挡炮、护盾保护、陷阱、当前可选目标增加悬停／键盘聚焦提示。普通格、落空、命中不弹提示。冻结、轰炸等使用当前卡牌名及选择要求；非法棋盘不亮待选框。

提示通过根节点浮层展示，按视口夹紧，不拦截格子点击，离开、滚动、切换棋盘和按 Escape 会关闭。

## 数据与边界

- 按实际规则，舰船陷阱来自「守株待兔」；「亡羊补牢」是取弃牌，不将其误标为陷阱。
- `ships` 子项新增可选布尔 `trap`，仅在本人实时舰船更新及重连快照中提供。旧载荷缺字段视为没有陷阱。没有新增顶层协议或数据库表。
- 陷阱广播只保留公开的设置者，不广播位置；本人通过自己的舰船快照得知位置。对手不显示陷阱。
- 对手护盾仅使用已有公开的 `opponent_shielded_ships`，不推测隐藏舰位。
- 真正命中优先于旧挡炮记录；重新获得护盾优先显示当前完整护盾。
- 既有格子测试标识和 `data-cell` 兼容字段保留，新增 `data-visual-state` 表示本轮视觉状态。
- 不改攻击、护盾消耗、陷阱触发和魔法选区的服务端结算规则。
