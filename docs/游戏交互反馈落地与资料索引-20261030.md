# 游戏交互反馈落地与资料索引

日期：2026-10-30。分支：`review/main-ui-vue-port`。本轮研究依据见 [游戏交互音效与按钮质感调研](游戏交互音效与按钮质感调研-20261030.md)。

## 实际落地

- 新增十种原创短音：轻扣、切换、返回、确认、拒绝、布船、撤船、完成、匹配成功、倒计时。采用短促机械与轻金属音色，不使用第三方游戏采样。
- 常规按钮、链接、页签、开关和滑杆接入统一反馈；鼠标、触摸产生的原生点击以及键盘 Enter/Space 走同一激活入口。悬停不发声。
- 布船、撤船、随机布阵、清空和战斗目标选格按实际状态变化发声；规则拒绝保留原因文字。普通开火沿用既有命中、未命中和击沉音。
- 匹配成功播放独立提示，最后三秒播放倒计时；猜拳结果、新成功通知和错误通知有相应反馈。声音不从日志文字或历史状态重放推断。
- 设置 → 声音增加“界面反馈音效”独立开关，仍服从总音效静音与音量。关闭界面声保留战斗声；退出战斗或切换房间只清理旧战斗声音。
- 按钮增加上沿薄高光、底座阴影和按压深度，沿用现有深海、蓝灰、紫色主操作和青金语义色。保持原有尺寸、字体和布局，卡牌美术不套用通用按钮材质。
- 航图、夜航、航海日志分别沿用各自的颜色，减少动效时保留静态材质并去掉按钮位移与过渡。

研究中的旋转舰船、单独奖励音等属于候选设计，本轮没有声称全部实现；当前单格舰船没有旋转流程。

## 浏览器声音时序

UI 素材提前解码；浏览器尚未解锁音频时，只允许在真实短暂用户手势内排入已经就绪的界面音源并恢复上下文，避免首次快速点击漏音。没有就绪的声音直接跳过，不在下载后补播旧操作。后台页面不播放新反馈。

这与浏览器的异步音频恢复和短暂用户激活约束有关，参见 [MDN AudioContext.resume](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/resume) 与 [MDN UserActivation.isActive](https://developer.mozilla.org/en-US/docs/Web/API/UserActivation/isActive)。实现细节和测试设备不等同于全部浏览器兼容性保证。
