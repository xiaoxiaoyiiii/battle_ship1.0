# 疗愈选舰与棋盘显示修复

## 玩家行为

- 打出疗愈前，在自己的棋盘选择一艘或两艘沉船，再确认。取消不消耗卡牌。
- 只复活玩家选中的船，不自动补选其它沉船；其它沉船继续显示红叉。
- 复活舰再次被击沉后，双方恢复红叉，移除该格复活标记。
- 普通出牌、连锁响应和阶段转换时点使用同一选择规则。大师 AI 显式提供合法沉船目标。

## 根因与改动

此前效果直接复活沉船列表最后两艘，没有读取玩家目标。复活广播又用“全部旧沉船与棋盘舰船的交集”生成，所以尚未复活的沉船也被标成复活；前端把累计的复活标记画在击沉标记之前，导致再次击沉后仍是灰色箭头。

- precheck 统一验证己方、不同沉船、数量一至二和原位置未被活舰占用；扣牌前验证，结算前再次验证。
- deck 的原地复活函数支持指定船对象，保持其它调用者的默认行为。疗愈仅广播本次实际复活的位置。
- 前端增加己方沉船目标类型，沿用现有选择横幅和确认按钮；移除再次命中、击沉格的历史复活标记，当前击沉状态优先显示。
- 连锁验证失败保留原响应窗口和手牌，不留下半关闭窗口。
