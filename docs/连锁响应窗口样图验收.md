# 连锁响应窗口样图验收

按用户提供的重构前 main 样图调整响应窗口，常驻连锁卡牌竖栏保持原有实现。沿用 Vue 与现有连锁协议。

- 居中 420px 窗口、浅金色「连锁」徽标、紫色触发卡名、金色圆环倒计时。
- 可响应卡改为纵向列表，显示卡名、速阶和两行效果摘要；底部并排「暂时收起·查看棋盘」「不响应」。
- 触发卡名和候选卡支持悬停、键盘聚焦预览完整效果；预览约束在面板范围内。
- 触屏第一次点击预览，第二次点击确认；独立保存确认状态，避免聚焦事件使首次点击直接出牌。
- 收起仅改变可见性，重开继续原倒计时；只有显式出牌或「不响应」发送对应响应。
