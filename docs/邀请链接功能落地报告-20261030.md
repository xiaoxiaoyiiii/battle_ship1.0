# 房间邀请链接功能落地报告

日期：2026-10-30。当前交付分支：`review/main-ui-vue-port`。

## 功能范围

- 自己创建房间后，在大厅的“我的房间”区域显示“复制邀请链接”。
- 链接格式为当前站点的 `/lobby?room=<房间号>`，只携带房间标识，不放入 token、密码或用户名。
- 从首页打开带合法房间号的链接，会先进入大厅，再复用已有 `join_room` 流程。
- 大厅 socket 尚未连接时等待同一连接就绪；同一页面实例和同一会话不会重复自动加入。
- 只有服务端返回成功后才写入“已加入”记忆。房间不存在、已满、已开始、权限失败或网络失败不会写入成功标记，刷新后仍可重试。
- Clipboard API 不可用或失败时弹出带完整链接的手动复制提示，并显示失败原因。

## 复用的现有能力

邀请链接没有新建房间状态，也没有绕过后端规则。创建和加入仍使用大厅已有的 `lobby_create_room` 与 `join_room`；房间容量、房间状态和权限继续由服务端判断。

## 当前边界

链接分享依赖浏览器允许剪贴板写入；手动回退可覆盖不安全上下文和权限拒绝。邀请链接只负责带入房间，不替代好友邀请、公开房间列表或登录权限。
