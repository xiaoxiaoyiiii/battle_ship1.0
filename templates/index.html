      排位赛规则

      • 怎么进排位：首页点「排位对战」加入队列，配对成功后打一场排位赛。 需要登录 —— 游客点它只会被提示先去登录，不会排队。
      • 什么情况不给分：赛前投降、人机局、自定义房 —— 这些对局不计排位分（也不会掉分），只有排位队列里配对出来的对局才结算。
      • 0 分封底：排位分最低 0 分，不会掉成负数； 触底那一局会在结算面板上写明「已到 0 分下限」。
      • 每个段位分 Ⅰ / Ⅱ / Ⅲ 三个小段位、每小段同样多的分； 赢了往上走、输了往下掉，跨小段位会自动进位 / 降级。

      计分规则

      计分规则加载中…

      在哪里看段位

      • 个人信息里的段位块（图标 + 段位文案 + 进度条）：点自己的头像打开。
      • 匹配等待界面：双方各自的段位图标与文案都显示在对手 / 自己那一行。
      • 排行榜 → 「段位榜」页签：按排位分排序，突出段位高低。
      • 个人信息编辑面有「段位公开」开关：关掉之后别人在你的个人信息里 看不到段位（本人永远看得到自己的）。
      • ⚠️ 段位榜不受这个开关影响：榜是公共竞技数据， 关掉「段位公开」之后你仍然在榜上 —— 开关只管个人信息里那一块。

      如需详细规则请咨询管理员。
